# ariboren/tap

Homebrew formulae for [margin](https://github.com/ariboren/margin), a tool for reviewing AI-written markdown like a Google Doc.

## Install

```sh
brew install ariboren/tap/margin
```

This also installs [Bun](https://bun.sh), which margin runs on.

## Upgrade

```sh
brew update
brew upgrade margin
```

The formula follows new npm releases automatically, usually within a day.

margin is also on npm as [`margin-md`](https://www.npmjs.com/package/margin-md), for installing with `bun add -g margin-md`.
